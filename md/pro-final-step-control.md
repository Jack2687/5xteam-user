# 全自动最后一步暂停

Pro 管理「流程中」的按钮为「停止全自动最后一步 / 启动全自动最后一步」。暂停时其他筛选页也能看到启动按钮。

- 统一控制自动空间合并、删除账户、API 商户和合并空间 2.0，包括额度达标、推送超时、每日定点、降智触发及后台续跑。
- 登录、开通、获取凭据、推送、额度检测和降智观察照常执行。暂停不消耗触发重试次数。
- 停止取消正在执行和排队的自动最后步骤。已经发给上游的操作无法撤回，受理事实仍会保存；结果不明时继续保留人工核实保护。
- 启动仅恢复调度，不在按钮请求中执行账号操作。未提交的账号重新按当前条件判断；已受理的商户/删除申请沿用原请求核验。因本开关暂停的合并 2.0 在原定时周期后续跑未完成部分，不重新提交已受理请求；其他失败或未知的 2.0 不会因此自动续跑。
- 单账号菜单里明确选择「执行或续跑」某一种最后步骤仍可人工执行；单账号「停止全自动」仍保持其原含义。

新控制接口为 `PUT /api/pro-settings/auto-final-step-control`，请求体 `{"paused":true}` 或 `{"paused":false}`。旧 `/auto-delete-control` 保留兼容；持久化与返回字段继续使用 `auto_delete_paused`，升级不重置已有暂停状态。全自动设置保存不会覆盖此独立开关。
