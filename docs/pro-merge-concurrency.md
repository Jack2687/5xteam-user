# Pro 并发配置

- Pro 全自动配置 → 高级设置 → 并发账号数：控制从登录开始的活动链条；登录、开通、凭证、推送、额度查询、合并都在链条内。持久化等待下次额度检测时释放名额，下次执行重新排队。
- Pro 全自动配置 → 空间合并 → 合并并发数：独立控制完整四步合并任务，范围 1～20，默认 2。旧配置没有此字段时默认 2。

全自动进入合并时同时受两项限制。手动合并、额度触发、超时触发、迁移续跑、后台移出补做和下游清理共用合并上限。合并名额覆盖邀请、进入、合并、母号移出、重试等待及后续分组调整或运行环境清理，成功、失败或取消后释放。

同一母号空间严格串行执行四步流程：上一个账号移出结束，下一账号才可开始邀请。锁按 Team ID 隔离，即使多个母号记录指向相同空间也不能同时操作。同母号排队不占用合并名额，不同母号可在合并上限内并行。移出完成后的下游处理保留合并名额，但不继续占用母号锁。

例如全流程并发 6、合并并发 2：最多 6 条全自动活动链条，其中最多 2 条执行合并；这 2 条还必须属于不同母号空间。同母号仍一次执行 1 条。

保存新并发值后，排队任务按新值领取名额。调低上限不会中断运行中的任务，运行数量降到新上限以下后再放入新任务。
