# 自动补货恢复、死号与分时备用卡台

## 设置入口

- Pro 管理 → 全自动配置 → 开通设置 → 分时开通：每段分别选择主卡台、套餐、备用开关、备用卡台。时段外及手动开通用单独备用开关。默认关闭，不修改已有正式配置。
- 银行卡与补卡：两卡台都须启用自动开卡，并配置对应 5x／20x 的 OAI 模板、开卡数量及金额预算。备用卡台保持本次套餐、付款供应商、国家及推送分组。
- 自动补货 → 配置：死号后暂停自动补货；按有效容量分档的触发／目标利用率。启用分档时默认小容量 80%／75%，120 起 85%／80%，可修改。关闭分档仍使用原固定配置。
- 补货顶部“当前规则”显示备用状态、平台、套餐和模板；当前在途任务已切换时显示实际方向。

## 执行边界

仅主卡台明确返回开卡余额不足才尝试备用。原开卡或付款结果不确定、预算不足、模板错误、代理错误均不能被当成余额不足。已领取任务固定时段规则，跨时段不改已启动任务；最多切换一次，已开卡待导入沿用原卡。

连续智商检测失败达到阈值后调用下游普通测试连接。正常则恢复；明确 account_deactivated／deleted or deactivated 等死号证据才转死号。普通 401、代理 504 不构成死号。死号停止最后一步及开通，按原账号下游移动至配置的合并后分组；不伪造合并、删除、商户成功或回款结果。主动删除已提交／合并已受理的预期失效排除在亏损死号之外。

两卡台关联卡永久禁用于新开通，删除和重新导入不解除。已确认付款可继续退款、提取余额及销卡；结果未知的付款保留核实限制。成本单列未收回本金为死号亏损，实际退款冲减本金；同笔本金不再重复计清算成本，服务费保留原计算。

补货准备失败，必须同时确认没有活跃任务、开卡意图、卡号和付款提交才释放在途。环球明确拒绝的 TOTP 登录跨到下一时间步重试一次。代理 CONNECT／传输失败使用独立有界重试和新粘性会话，保留同一业务账号及付款身份，不重放已成功或结果未知的付款。代理供应商仍不可达时有明确失败结果，不无限占用准备流程。
